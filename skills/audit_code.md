# Skill: Audit Code

## Objective
QA Engineer（@qa）として、`src/` 内のコードを監査し、依存関係の欠落、構文エラー、未処理エラー、セキュリティ脆弱性、ロジックバグ、および**リファクタリングによる既存機能のデグレード（先祖返り・破損）**を検出・修正する。

## Rules of Engagement
- **対象ディレクトリ**: `src/`
- **基準ドキュメント**: `docs/spec.md`
- **デグレード防止**: リファクタリング時は、既存の要件や機能が壊れていないか、インターフェースの整合性が保たれているかを最重要視する。
- **直接コミット**: 修正が必要な箇所は直接 `src/` 配下のファイルを上書き・修正する。
- **CLI連携**:
  - プロジェクト横断のセキュリティチェック、型整合性の検査、リファクタリング前後の差分レビューには **Claude Code CLI**（`claude -p --output-format text "<code-or-diff>"`）を活用する。

## Instructions
1. 仕様書（`docs/spec.md`）と `src/` 内の実装・差分を比較検証する。
2. 構文エラー、インポート漏れ、型定義の不整合、セキュリティホール、デグレードの有無を検出する。
3. 問題箇所を修正し、修正済みのクリーンなコードを `src/` に反映する。

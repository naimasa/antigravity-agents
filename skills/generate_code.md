# Skill: Generate Code（@engineer）

承認された `docs/spec.md` に基づき、新規実装または既存コードのリファクタリングを行い、`src/` に完全な動作コードを生成・更新する。

## Rules
- **新規**: 仕様書指定の言語・フレームワークに厳密に従い、完全なファイル群を生成する。
- **リファクタリング**: 既存のコードベースとコーディングスタイルを尊重し、不要な全置換を避けて**対象箇所のみ安全に差分改修**する。既存の正常な機能やコメントを無闇に消さない。
- **出力先**: すべてのソース・設定ファイルを `src/`（またはプロジェクトルート）に正確なフォルダ構造で配置する。**省略・プレースホルダーは禁止。**
- **CLI連携**: 複雑なアルゴリズム導出・データ構造設計・ボトルネック関数の局所最適化は Codex CLI を使い、生出力を `docs/runs/$RUN_ID/raw/` へ保存する（`codex exec -o ...`）。
- **記録**: `track_progress.md` に従い完了直後に `@engineer` エントリを追記 → `git add -A && git commit -m "feat: <概要> (<RUN_ID>)"`。これにより後続の @qa の修正差分が独立して見える。未実装・積み残しは Findings に必ず列挙する。

## Instructions
1. `docs/spec.md` を精読し、要求と変更範囲（新規 / リファクタリング）を把握する。
2. 既存コードがあれば構造を把握したうえで、適切なファイルへ修正・機能追加を適用する。
3. `src/` へ完全に出力・更新する。

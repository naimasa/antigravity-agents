標準ライブラリのみの Python 製 TODO 管理 CLI を `src/todo.py` に作成してください。

- 実行形式: `python3 src/todo.py --file <JSONパス> <サブコマンド> ...`
- `add "<text>"`: 新規タスクを追加し、採番した整数 ID だけを標準出力に表示（ID は 1 から連番、削除後も再利用しない）
- `list`: 1 タスク 1 行 `<ID> [ ] <text>`（完了済みは `[x]`）を ID 昇順で表示。0 件なら何も出さない
- `done <ID>` / `rm <ID>`: 成功時は終了コード 0。存在しない ID は標準エラーにメッセージを出し終了コード 1
- データは `--file` の JSON に永続化（ファイルが無ければ空として扱い、add 時に作成）
- テストも `tests/` に用意すること
